  • ⚠️ P0 重构: 字段按"内存 / GPIO / 文件 / UI / 日志 / 时间 / 退出"分组重排; 加 static_assert 字段偏移
  • ⚠️ P0 重构: plugin init() 里检查每个函数指针非 NULL
  • ⚠️ P0 重构: 加 fat_last_error() 让 plugin 拿到详细 err 码
app/app_loader.c 511 行 P0 拆 4 文件
  • 导出: app_loader_init / run / on_touch / on_tick / unload_current
  • 依赖: app_loader.h app_manager.h lcd.h ff.h ui_draw.h ui_btn.h ui_tile.h hardware/gpio.h
  • 角色: plugin 主循环。32KB RAM 池 (0x20038000..0x20040000), s_plugin_fat_mounted flag 防 mount 状态失效, .papp 头 4 字节 magic 检查, 入口跳转, host_api 函数指针表填充

  • ⚠️ P0: 拆 4 文件 — app_loader.c 主循环 / app_host_api.c 函数指针表 / app_plugin_slot.c 32KB RAM 池 / app_plugin_fat.c mount 状态
  • ⚠️ P0: 加 .papp size sanity check (不能超 32KB)
  • ⚠️ P1: 加 30s 健康检查, mount 状态跟内核对不上时自动重 mount
